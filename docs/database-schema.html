Design decisions

Price lives on the day, not the meal

This mirrors calcChild() in the parent order page. A chef_both day is one bundled price covering two meals, and the RM 1.00 combo discount is earned by the day (breakfast and lunch both picked), not by either meal alone. Putting price on OrderMeal would force an arbitrary split.

Orders snapshot everything they depend on

OrderMeal stores itemNameSnapshot, unitParentPrice and unitVendorCost; Order stores subtotal/discount/total and its own allergies array. Editing prices in /admin/prices, renaming a dish, or updating a student’s standing allergies never rewrites an order that was already placed.

Money is Decimal(10,2), never Float

Every currency column is @db.Decimal(10, 2). Prisma returns these as Decimal objects — don’t coerce to Number before arithmetic.

Dates are real DATE columns

MenuOffering.date, CalendarBlock.date and OrderDay.date are @db.Date, built with Date.UTC so a Malaysian timezone offset can’t shift a meal onto the wrong school day.

Cascade down the order spine, set-null across it

Deleting an Order removes its days and meals (cascade) — they have no meaning alone. Deleting a User, PlanOption or MenuItem nulls the reference instead, because the order itself must survive; that is what the snapshot columns are for.

Prisma 7 specifics

The client needs the PrismaPg driver adapter rather than connecting on its own, the generator is prisma-client-js (the newer prisma-client emits TypeScript this plain-JS project can’t import), and the connection URL lives in prisma.config.ts, not in the schema. DATABASE_URL is pooled for the app; DIRECT_URL is unpooled for migrations, which cannot run through pgBouncer.

Not wired up yet

The schema is migrated and seeded, but no page or API route reads from it — the UI still renders entirely from the static lib/*.js modules, and prisma/seed.js seeds the database from those modules. So lib/menuData.js, lib/schoolCalendar.js, lib/pricingData.js and lib/mockOrders.js remain the source of truth for June 2026 until an admin UI can create cycles. Porting the pages over is the outstanding work.
